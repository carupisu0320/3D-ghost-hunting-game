ゴーストハンティング ロビー
クリックして歩き回る
WASD: 移動 / Shift: 走る / マウス: 見回す / Esc: 一時停止(クリックかWASDで再開)
奥の工房のホワイトボードで、部屋づくり・参加・マップ選択ができます
工房の壁のボードから道具を取って(クリック)、ガレージのテスト用ゴーストで試せます
1〜3: 持ち替え / E: 使う / Q: ボードに戻す
コントローラー: 左スティック=移動 / 右スティック=見回す / Y=選ぶ・取る / X・ZR=使う / L・R=持ち替え / 十字キー下=戻す / ZL=走る / +=一時停止
ゲーム中のコントローラー: +=調査書を開く・閉じる(十字キー=移動 / B・Y=選ぶ・チェック / X=特定 / A=閉じる)
(コントローラーのボタンを押すと、クリックしなくても始まります)
クリックで操作を再開
(WASDなどのキーでも再開できます / Esc: 一時停止)
